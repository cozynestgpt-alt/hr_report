# 월례회의 인원보고서 자동화

GitHub: https://github.com/cozynestgpt-alt/hr_report (저장소명은 hr_report로 유지)

## 폴더 구조

```
부서별인원현황/
├── main.py                  ← 실행 스크립트
├── README.md
├── input/                   ← 매월 갱신 파일 넣는 폴더 (.gitkeep)
│   ├── 부서별인원현황_YYYYMMDD.xlsx   (기준월 말일자, 전년동월 파일도 함께 보관)
│   └── ★월례회의_인원보고_양식.xlsx   (중간관리·물류센터용역 수기입력 양식, 매월 담당자가 직접 갱신)
├── template/                ← 고정 템플릿 (수정 금지)
│   └── 월례회의_인원보고_템플릿.xlsx
├── output/                  ← 결과물 자동 생성 (.gitkeep)
│   └── 월례회의_인원보고_YYYYMM_생성일자.xlsx   (동일 파일 존재 시 _v2, _v3...로 자동 증가)
├── DB/                      ← 참조용 DB 파일 (.gitkeep)
├── 참고/                    ← 집계 방법 문서·과거 산출물 (.gitkeep)
└── scripts/                 ← 내부 유틸 (수정 금지)
    └── recalc.py
```

> `input/`, `output/`, `DB/`, `참고/` 폴더는 개인정보가 포함된 실데이터라 `.gitignore`로 제외됩니다.
> 폴더 자체는 `.gitkeep` 파일로 저장소에 유지되므로, 새로 clone하면 빈 폴더 구조는 그대로 생기고 그 안에 매월 파일만 채워 넣으면 됩니다.

## 사용법

### 기본 실행 (당월 자동 적용)
```bash
python main.py
```

### 특정 월 지정
```bash
python main.py 202605
python main.py 202604
```

## 매월 작업 순서

1. **input 폴더**에 기준월 말일자 `부서별인원현황_YYYYMMDD.xlsx` 파일 복사 (전년동월 파일도 폴더에 남아있어야 함)
2. **input/★월례회의_인원보고_양식.xlsx**를 열어 중간관리(롯데/현대/신세계/갤러리아)·물류센터용역·평택점용역 값과 L2(기준일)를 당월 기준으로 직접 갱신
3. 터미널에서 실행:
   ```bash
   python main.py 202605
   ```
4. **output 폴더**에서 결과물 확인
   - `월례회의_인원보고_202605_생성일자.xlsx` → 보고용 엑셀 (수식 재계산까지 자동 완료)
   - 2번 항목이 정상 갱신되어 있었다면 행 34~37, 43~44도 자동 반영됨. 안 되어 있었다면 콘솔에 경고가 뜨고 해당 셀은 비워짐
5. Excel을 열어 아래 항목은 직접 입력
   - (2번을 안 했거나 기준일이 안 맞았을 경우) 행 34~37: 중간관리 전년·당년 인원, 행 43~44: 물류센터용역·평택점용역 인원
   - 신규입사자명단·퇴사자명단 시트

## 주의사항

- `template/` 폴더의 템플릿 파일은 수정하지 마세요 (시트 구조가 바뀌면 스크립트 수정 필요)
- input 파일명은 `부서별인원현황`으로 시작해야 자동 인식됩니다
- `★월례회의_인원보고_양식.xlsx`의 L2(기준일)가 당월 말일과 다르면 자동 반영을 건너뜁니다 — 매월 실행 전 반드시 갱신하세요
- 같은 월 재실행 시 output 파일을 덮어쓰지 않고 `_v2`, `_v3`...로 새로 저장됩니다
